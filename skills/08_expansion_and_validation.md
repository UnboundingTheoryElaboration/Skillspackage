# Skill 08: Literature Discovery and Method-Open Validation Suite (`08_expansion_and_validation.md`)

## 1. Scope (`expansion_enabled = True`)
Governs protocol-driven literature search (`G0_discovery`) and independent multi-scholar validation benchmarking (`G7_validation`).

## 2. Seven Method-Open Validation Scenarios
In addition to testing evidence fidelity, cross-study translation, consequential human gates,branch sensitivity, and out-of-sample transfer, validation tests **methodological openness**:
1. Rich temporal narrative with weak static comparability -> System must recommend Process-Sequence pathway rather than forcing static QCA.
2. Multi-dimensional outcome where single binary collapse conflates defensive stasis with generative co-evolution -> System must disaggregate regimes.
3. Conceptual propositions without bounded empirical cases -> System must route to Conceptual Elaboration Register, never fabricating case scores.
4. Narratively described actor interactions without parameterized transition rules -> System must output an ABM Specification-Gap Report rather than an invented simulation.
